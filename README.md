# Elk Fish Robotics

A static single-page website for Elk Fish Robotics, a Western Australian DJI Agras drone dealer based in Fremantle.

The site introduces the DJI Agras T100 agricultural spraying and spreading drone to Australian growers, contractors and agribusiness operators, and gives them a way to enquire about a demo, a quote or a training session.

## Contents

- `index.html` - the single page
- `Agras_t100_hero_video_1.mp4` - hero background video
- `hero-poster.jpg` - poster image shown while the video loads or as a fallback
- `EFR_LOGO.png` - Elk Fish Robotics logo

## Hosting

This site is deployed on GitHub Pages and served from the `main` branch root.

## Updating the site

To push a change after editing files locally:

```
git add .
git commit -m "Describe what changed"
git push
```

GitHub Pages will rebuild within a minute or two.
